Download Tanis Terminal

Free and open source. Pick your system below. Tanis Terminal updates itself when a new version comes out.

  • Windows

    Windows 10 and 11, 64 bit. The installer is for your user only and needs no administrator rights. It adds Tanis Terminal to the Start menu, puts tterm on your PATH and adds Open in Tanis Terminal to the Explorer menu of folders. It updates itself. The portable zip needs no installer at all.

    Download the installer File tterm-…-windows-x86_64-setup.exe Download the portable zip File tterm-…-windows-x86_64-portable.zip

  • macOS

    Apple silicon (M1 and later). Open the disk image and drag Tanis Terminal to Applications. It updates itself.

    Download the disk image File tterm-…-macos-arm64.dmg

  • Linux

    x86_64, any distribution. The install script below installs it for your user and keeps it up to date. Or download the tarball and unpack it where you like.

    Download the tarball File tterm-…-linux-x86_64.tar.gz

Command line

Install from a terminal

On Linux, one command installs Tanis Terminal and, run again, updates it.

Any Linux distribution install script

Installs Tanis Terminal for your user under ~/.local, no sudo, with its launcher entry and icons. It then updates itself, or run the script again. Options and uninstall.

$ curl -fsSL https://terminal.tanis.codes/install.sh | bash

macOS terminal

A Mac app cannot put itself on the PATH. To run tterm from another terminal, link it once:

$ sudo ln -sf /Applications/tterm.app/Contents/MacOS/tterm /usr/local/bin/tterm
First launch

A note on unsigned builds

Tanis Terminal is not code signed yet, so your system asks once before opening it.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/tterm.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

Tanis Terminal builds with the stable Rust toolchain and Zig 0.17. Clone the repository and run make release. The README lists the system libraries Linux needs.
