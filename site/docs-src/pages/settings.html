Settings

Open Settings with the gear button of the bar or Ctrl ,. Every change applies at once and is saved to settings.toml, a plain text file you can also edit by hand.

Where the file lives

  • Linux: ~/.config/tterm/settings.toml (or under $XDG_CONFIG_HOME)
  • macOS: ~/Library/Application Support/tterm/settings.toml
  • Windows: %APPDATA%\tterm\settings.toml

Settings, General shows the path of yours. A value that is missing or not valid takes its default.

Profiles

Settings, Profiles edits them; in the file they look like this:

```toml title="settings.toml" default_profile = "claude · telaio" hidden_profiles = ["fish"] profile_order = ["claude · telaio", "zsh"] [[profiles]] name = "claude · telaio" cwd = "~/dev/telaio" startup = "claude" color = "indigo" shortcut = 3 ```
KeyMeaning
default_profileThe profile a new tab opens. The first one when missing.
hidden_profilesDetected shells left out of the menus.
profile_orderThe order of the profiles in the menus and of their number shortcuts, by name. Profiles it does not name come after, detected ones first. Written when a profile is dragged in Settings, Profiles.
nameThe name of the profile and of its tabs.
shellThe program to run. Your default shell when missing.
cwdThe folder the tab starts in; ~ is your home.
startupA command typed into the shell once it is ready.
colorindigo, green, blue, yellow or gray.
shortcut1 to 9: Ctrl Shift and that number opens it.
