title: Installation description: How to install Tanis Terminal on Windows, macOS and Linux, how it updates, and how to build it from source. ---

Installation

Every release on GitHub has files for Windows x86_64, macOS on Apple silicon and Linux x86_64. The download page links to them.

Windows

Run tterm-X.Y.Z-windows-x86_64-setup.exe. It installs Tanis Terminal for your user only, under %LOCALAPPDATA%\Programs\tterm, and needs no administrator rights. The installer offers three options:

  • Add tterm to the PATH, checked: run tterm or tterm C:\projects\app from any new console. Uninstalling removes it again.
  • Add "Open in Tanis Terminal" to the Explorer menu, checked: on folders and on the background of an open folder.
  • Create a desktop shortcut, unchecked.

To use it without installing anything, unzip tterm-X.Y.Z-windows-x86_64-portable.zip and run tterm.exe.

macOS

Open tterm-X.Y.Z-macos-arm64.dmg and drag Tanis Terminal to Applications. A Mac app cannot put itself on the PATH; to run tterm from another terminal, link it once:

```shell $ sudo ln -sf /Applications/tterm.app/Contents/MacOS/tterm /usr/local/bin/tterm ```

Linux

Install script

On any distribution, one command installs the latest release for your user, with no sudo:

```shell $ curl -fsSL https://terminal.tanis.codes/install.sh | bash ```

The script downloads the tarball of the latest release from GitHub, checks it against the release's SHA256SUMS and installs it under ~/.local: the program in ~/.local/bin/tterm, and the menu entry and the icons under ~/.local/share. It keeps the list of the files it installed, so updating and uninstalling touch exactly those. If ~/.local/bin is not on your PATH, it says so; the menu entry works either way.

Options go after bash -s --:

```shell $ curl -fsSL https://terminal.tanis.codes/install.sh | bash -s -- --version 0.1.0 $ curl -fsSL https://terminal.tanis.codes/install.sh | sudo bash -s -- --prefix /usr/local $ curl -fsSL https://terminal.tanis.codes/install.sh | bash -s -- --uninstall $ curl -fsSL https://terminal.tanis.codes/install.sh | bash -s -- --uninstall --purge ```

--uninstall keeps your settings and logs; --purge removes them too.

Tarball

tterm-X.Y.Z-linux-x86_64.tar.gz holds bin/tterm, the desktop entry and the icons in a /usr like layout, and the install script. Unpack it anywhere and run bin/tterm, or run its install.sh --tarball to install it.

Tanis Terminal needs a graphics driver with Vulkan, which every current distribution has. It runs on Wayland and on X11.

Updates

Once after it starts, Tanis Terminal checks GitHub for a new version. On Windows, on macOS and in a Linux copy the install script put under your home, it downloads it in the background and checks it; then the bar shows X.Y.Z ready · Restart. Restarting closes every tab, so it always asks first. The portable zip and a tarball you unpacked by hand only tell you a new version exists. Turn the check off in Settings, About.

Building from source

Tanis Terminal builds with the stable Rust toolchain and Zig 0.17, which compiles libghostty-vt. Clone the repository and run make release; the binary is target/release/tterm. The README lists the libraries Linux needs.
