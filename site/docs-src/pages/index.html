Tanis Terminal

Tanis Terminal (tterm) is a fast, native terminal for Linux, Windows and macOS. It runs your shells in tabs and profiles, draws on the GPU, and does no work while nothing changes on screen.

What it is

  • Ghostty's emulation. The terminal emulation is libghostty-vt, the parser and screen state of the Ghostty terminal, so full screen programs, colors, the Kitty keyboard protocol and mouse reporting behave as they do there.
  • Native. Written in Rust on gpui, the GPU accelerated UI framework of the Zed editor. No browser engine inside.
  • Tabs and profiles. The shells of your machine are found for you, and your own profiles add a folder, a command to start with, a color and a shortcut. See Tabs and profiles.
  • Made for coding agents. A screenshot pasted or dropped into a tab becomes a file path at the prompt, and a screen shows the tokens Claude Code used. See Coding agents.
  • Idle means idle. No timers and no polling. The cursor blinks for a few seconds after you type, then stays still.
