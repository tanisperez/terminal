Coding agents

Coding agents such as Claude Code run in a terminal. Tanis Terminal makes the common steps short: show the agent a screenshot, start it in the right folder, and see how much it worked.

Screenshots

Take a screenshot and press Ctrl V in a tab. Tanis Terminal saves the image as a PNG and types its path at the prompt, quoted for your shell, ready for the agent to read. Dropping an image file from your file manager types its path the same way; a box shows the image before you let go.

Pasted images are kept in the cache folder of your system, never in Downloads, so a resumed session still finds them:

  • Linux: ~/.cache/tterm/images/
  • macOS: ~/Library/Caches/tterm/images/
  • Windows: %LOCALAPPDATA%\tterm\cache\images\

Images older than 14 days are deleted when Tanis Terminal starts. Change the number of days with pasted_images_days, or turn the feature off in Settings.

A profile per project

A profile with a folder and a startup command opens a tab with the agent already running there, for example a profile named claude · telaio with the folder ~/dev/telaio and the command claude. Give it a shortcut and it is one key away. See Your own profiles.

Agent usage

The chart button in the bar opens the usage of Claude Code: input and output tokens, tasks and active time for the last 7, 30 or 90 days or all of them, a bar per day and the share of each model. On the left, the tabs where it runs now. Esc goes back to the terminal.

  • The numbers come from Claude Code's logs on your computer (~/.claude/projects). Only the usage figures are read, never the content of your sessions, and nothing is sent anywhere.
  • Input tokens include the ones read from and written to the cache; the tooltip of each bar breaks them down.
  • On Windows, the logs of the WSL distributions that are running count too.
  • The tabs where it runs now are found on Linux, Windows and macOS. In a WSL tab, Claude Code runs inside the distribution, where Windows cannot see it: such a tab is not listed yet.
  • Other agents are not counted yet.
