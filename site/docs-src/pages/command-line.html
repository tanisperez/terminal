title: Command line description: The tterm command: opening folders in tabs, the options, and the environment variables Tanis Terminal reads and sets. ---

Command line

The installers put tterm on your PATH (on macOS, link it as shown in Installation).

```shell $ tterm # one tab in your home folder $ tterm ~/dev/app ~/dev/api # one tab in each folder $ tterm -- -odd-name # after --, every argument is a folder ```

Options

OptionMeaning
-h, --helpPrint the help and exit.
-V, --versionPrint the version and exit.

Environment variables

Tanis Terminal reads TTERM_LOG, the log level of one run (off, error, warn, info, debug or trace), over the one in Settings.

It sets these for the programs in its tabs:

VariableValue
TERMxterm-ghostty, with Ghostty's terminfo, which Tanis Terminal provides
COLORTERMtruecolor
TERM_PROGRAMtterm
