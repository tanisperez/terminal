Quick start

Open Tanis Terminal and your login shell starts in your home folder. These are the things worth knowing on the first day. On macOS, read Cmd where this page says Ctrl Shift.

Tabs

  • Ctrl Shift T or the + button opens a tab in the folder of the one you are in.
  • Ctrl Tab and Ctrl Shift Tab move between tabs; drag a tab to move it.
  • Ctrl Shift W, the cross or a middle click closes a tab. Right click a tab to close the others, the ones to its right or all.

Profiles

The arrow next to + lists your shells: the ones found on your machine and the profiles you add in Settings. Ctrl Shift Space opens the same list to pick from the keyboard. See Tabs and profiles.

Copy and paste

Select with the mouse, then Ctrl C copies. With nothing selected, Ctrl C stops the running program as usual. Ctrl V pastes. Right click for the same actions. See Copy, paste and links.

Links

Hold Ctrl and move over a URL: it is underlined. Click to open it in your browser.

Font size

Ctrl + and Ctrl - change the size of the text; Ctrl 0 goes back to the size in Settings. Ctrl , opens Settings, where the font, the theme and the cursor are.
