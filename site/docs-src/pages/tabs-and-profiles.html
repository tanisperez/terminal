Tabs and profiles

The tab bar is the title bar of the window. It always shows, with one tab too, so the new tab button and your profiles are at hand.

Tabs

A tab is named after the title the running program sets, or else after its shell and folder (zsh · terminal). A tab opened from a profile of yours keeps the profile's name.

  • Hover a tab to see its whole title, its folder and its profile, when the name is cut short.
  • The first tab of a window starts in the start folder, your home folder unless Settings, General, Start folder says otherwise.
  • A new tab starts in the folder of the active one, or in the start folder when New tabs open in says so. The shell reports its folder through its integration; on Linux, Tanis Terminal also reads it from the running program. A profile with its own folder always starts there.
  • Drag a tab onto another to put it in that place, or past the last tab to move it to the end. An accent line marks where it lands.
  • Right click a tab for Close, Close others, Close to the right, Close to the left and Close all.
  • When the only tab closes, the window closes. A single tab has no close button for that reason.

Detected shells

When Tanis Terminal starts, it lists the shells of your machine as profiles:

  • Linux and macOS: your login shell and the other shells installed (bash, zsh, fish and others).
  • Windows: every WSL distribution, PowerShell and the Command Prompt.

Detected profiles are not written to your settings. Hide the ones you do not use in Settings, Profiles.

Your own profiles

In Settings, Profiles, add a profile with:

  • Name, the name of its tabs.
  • Shell, the program to run, or the default shell.
  • Folder, where the tab starts.
  • Startup command, typed into the shell once it is ready, for example claude. The shell keeps running after the command ends, so the tab stays open.
  • Color of its chip in the menus: indigo, green, blue, yellow or gray.
  • Shortcut, Ctrl Shift 1 to 9 (Cmd Option 1 to 9 on macOS).

Drag a profile by its handle in Settings, Profiles to change its place in the menus, detected or yours. The order also gives the profiles without a shortcut of their own their number, Ctrl Shift 1 first. Reset goes back to the usual order. A star marks the default profile.

The default profile is the one a new tab opens. Profiles are saved in settings.toml; see Settings.

Opening a profile

  • The arrow next to + lists every profile with its shortcut.
  • Ctrl Shift Space opens a picker: the arrows move, Enter opens the tab, and each profile's number opens it directly.
  • A profile's own shortcut opens it directly.

Shell integration

bash, zsh and fish load Ghostty's shell integration scripts, with nothing to set up. The shell then reports its folder (OSC 7) and where each prompt starts (OSC 133). Programs see TERM=xterm-ghostty, COLORTERM=truecolor and TERM_PROGRAM=tterm. On Windows the WSL distributions run their own shells, which may not report their folder.
