Copy, paste and links

Copy and paste work with the keys you use everywhere else, and links open with a click while you hold Ctrl. On macOS, Cmd takes the place of Ctrl.

Selecting

  • Drag to select. A double click selects a word, a triple click a line.
  • On Linux the selection is also the primary selection: a middle click pastes it.
  • A program that uses the mouse (htop, vim with the mouse on) gets the clicks. Hold Shift to select anyway.

Copy and paste

  • Ctrl C copies the selection and clears it. With nothing selected, it is sent to the program, which usually stops it.
  • Ctrl V pastes. Pasting several lines does not run them one by one: shells that support bracketed paste get the text as one block.
  • Ctrl Shift C, Ctrl Shift V and Shift Insert also work.

Because Ctrl V pastes, programs no longer receive it as a key (a shell's quoted insert, for example), as in kitty with the same setup.

The right-click menu

A right click on the terminal opens Copy and Paste. On a link it adds Open link and Copy link. A program that uses the mouse gets the right click instead.

Links

Hold Ctrl and move over a URL: it is underlined and the pointer becomes a hand. Click to open it in your default browser. This works in programs that use the mouse too.

  • Links start with https://, http://, file:// or ftp://.
  • Punctuation that ends a sentence is left out, and so is a closing bracket without its opening one: in (see https://example.com/a). the link is https://example.com/a.
  • A long URL that reaches the right edge goes on in the next line, the way the terminal wrapped it.

Images and files

Pasting a screenshot saves it as a PNG and types its path, and dropping files types their paths. See Coding agents.
