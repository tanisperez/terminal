Troubleshooting

If something does not work, the log usually says why. When it does not, open an issue with the log attached.

The log file

  • Linux: ~/.local/state/tterm/tterm.log
  • macOS: ~/Library/Logs/Tanis Terminal/
  • Windows: %LOCALAPPDATA%\Tanis Terminal\logs\

For more detail, start it with TTERM_LOG=debug tterm. The log never holds what you type or the output of your programs.

macOS or Windows will not open it

Tanis Terminal is not code signed yet. On macOS, open System Settings, Privacy and Security, and choose Open Anyway. On Windows, in the SmartScreen warning choose More info and Run anyway.

A program shows the wrong characters or colors

Programs see TERM=xterm-ghostty. Over SSH, the remote machine may not know that terminal type; copy Ghostty's terminfo there, or set TERM=xterm-256color on that machine.

Ctrl+V does not reach my program

Ctrl V pastes, so programs do not receive it. Shells offer the same quoted insert on another key; see Copy, paste and links.

A new tab does not start in my folder

The folder comes from the shell integration of bash, zsh and fish. A shell whose startup files replace the prompt hooks, or a WSL distribution on Windows, may not report it. See Shell integration.
