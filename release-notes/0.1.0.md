The first release of Tanis Terminal, a native terminal emulator for Linux, Windows and macOS
built on libghostty-vt, Ghostty's terminal emulation.

## Highlights

- **Tabs in the title bar**: with one tab the window is all terminal; the bar shows from the second tab on.
- **Profiles**: the shells of the machine are detected (bash, zsh, fish, PowerShell, Command Prompt, the WSL distributions), plus the user's own profiles with a folder, a startup command, a color and a shortcut. A keyboard picker opens any of them (#5, #13).
- **Shell integration**: bash, zsh and fish report their folder and their prompts, and a new tab starts in the folder of the active one (#10).
- **Screenshots for coding agents**: a screenshot pasted or dropped into the terminal is saved as a PNG and its path is typed, ready for Claude Code (#3, #4).
- **Agent usage**: the tokens Claude Code used, per day and per period, read from its local logs (#6).
- **Mouse**: select text and copy it, and mouse reporting for full screen programs (#1, #2).
- **Keyboard input**: dead keys, AltGr characters and input methods (#9).
- **Fonts and icon**: Noto Sans Mono 12 pt bundled as the default font, with the font's own line height, and the app icon (#7, #8).
- **Install and updates**: on Linux, an install script (`curl -fsSL https://terminal.tanis.codes/install.sh | bash`) and a tarball; a dmg for macOS; an installer that puts `tterm` on the `PATH` and a portable zip for Windows. The app checks for a new version once after startup and installs it after a click (#11).
