A richer agent usage screen, a new look for the tabs, a strip of tabs that scrolls, What's new after
each update, the keyboard shortcuts on F1, editable detected profiles and WSL tabs that open where
you were.

## Highlights

- **Agent usage**: the screen now has three sections. Spend shows the 5-hour block against your largest one, with its pace and when it ends, how full the context of each agent open in a tab is, the cost at API prices against the period before, and where the tokens come from each day (cache reads, cache writes, new input, output). Projects lists each working folder by cost, with tokens, tasks, time and a trend, and the latest sessions with their peak context. Habits shows when the agents work by weekday and hour, the days with agents over 13 weeks, the average task and the models by week (#51).
- **Tabs**: a lighter bar, so the active tab stands out, with a shorter accent line over the middle of the tab, joined to the terminal at any display scale. Tabs are a fifth wider (#50).
- **Many tabs**: past their minimum width the tabs scroll, with the mouse wheel too, and the bar shows arrows and a list of every tab, as in Postino and ted. The active tab is always scrolled into view (#52).
- **What's new**: after an update, these notes open once in a window over the terminal (#53).
- **Keyboard shortcuts**: F1 (Cmd+Shift+/ on macOS) opens the list of every shortcut, with a filter (#48).
- **Profiles**: a detected profile can be edited, to change its start folder or anything else: Edit saves a copy that takes its place, and deleting the copy brings the detected one back (#47).
- **WSL**: a new tab opens in the folder of the WSL tab you were in. WSL shells now load the shell integration, so they report their folder and their prompts (#46). The usage screen finds Claude Code in WSL tabs too, by the title it sets, with its session from the distribution's logs (#43).
- **Resizing**: only the size, in columns and rows, shows while a window or a pane is resized.
- **Fixes**: the mouse reported to programs such as Claude Code on the cell under it (#44), typing inside Claude Code on Linux no longer feels delayed (#45), and the usage screen's bar has the height of the tab bar (#49).
