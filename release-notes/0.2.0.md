Split panes, tabs that move to their own window, your own colors and a translucent window, Nerd
Font icons in every font, and fixes from a first full day of use on Linux, Windows and WSL.

## Highlights

- **Split panes**: split a tab side by side or stacked with Windows Terminal's shortcuts (Alt+Shift+Plus, Alt+Shift+Minus, Alt+Shift+D), move between panes with Alt and the arrows, resize with Alt+Shift and the arrows or by dragging the line between them. Ctrl+Shift+W closes the pane with the focus (#33).
- **Move a tab to a new window**: from its right-click menu, with Ctrl+Shift+N, or by dragging it out of the window. What runs in it keeps running (#34).
- **Colors**: a new Colors page in Settings for the 16 colors, the background, the text, the cursor and the selection. The default palette is kitty's, with an inverted selection, and only the colors you change are saved, in `[colors]` (#30).
- **Background opacity**: from 50 % to 100 %, with the text always opaque (#31).
- **Nerd Font icons**: CaskaydiaCove Nerd Font Mono is the default font, and the Nerd Font symbols are the fallback of every font, bundled or installed. The font list has a search box and every font installed. A profile can have its own font and size (#35, #39).
- **Tab bar**: closer to Windows Terminal, with a gap above the tabs, room before the first one and the active tab joined to the terminal. Hover a tab for its whole title, its folder and its profile (#42, #36).
- **Profiles**: drag them in Settings to set the order of the menu and of the Ctrl+Shift+1…9 shortcuts; a star marks the default one (#32, #26).
- **Start folder**: the folder of a window's first tab, and whether new tabs open in the active tab's folder or there (#28).
- **Agent usage**: on Windows the logs of the running WSL distributions count too, and the tabs running Claude Code are found on Windows and macOS as on Linux (#29, #38).
- **Faster typing on Linux**: a typed key is painted about 16 ms sooner on Wayland, about 2 ms from key to screen (#24).
- **Fixes**: accented letters with dead keys on Wayland (#25), a drag selection that took one character too many (#37), the settings path wrapping on Windows (#27), and the window size saved by the window that closes (#40).
- **Website**: new screenshots, with the window's buttons, and sections for panes and colors (#41).
